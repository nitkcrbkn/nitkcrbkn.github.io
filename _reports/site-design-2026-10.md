# 全ページのデザイン改善（2026年10月）

## 調査と方針
対象は全17ページ。トップ、ロボット一覧、機体詳細5件、活動報告一覧、記事6件、支援・協賛、お問い合わせ、404。Jekyllの共通ヘッダー・フッター、テーマ切替、モバイルメニューも対象。

| ページ | 役割 | 調査時の問題 | 改善方針 |
| --- | --- | --- | --- |
| トップ | 団体と活動を知る | 大きな余白、定型的な二分割、ボタンの反復 | 団体名と大会写真を主役にし、報告・機体・地域活動に異なる構成を使う |
| 機体一覧 | 年度から機体を探す | 1機しかない年度も2列、写真のない機体が間延び | 年度の見出しを左に固定した構成、1機と2機で配置を変える |
| 機体詳細5件 | 仕組みと大会結果を読む | 概要・受賞・本文の重複、長い一段落 | 機体の特徴、競技、結果を分け、同じ大会の記事へ案内 |
| 活動報告一覧 | 記事を探す | 全記事が同じ行、写真が小さい | 写真のある大会記事を大きく、通常記事は日付と分類を明示。絞り込み対応 |
| 記事6件 | 活動の経緯を読む | 写真と本文が離れる、一段落に複数の話題 | 該当する写真と説明を一緒に置き、長い報告には見出しを設ける |
| 支援・協賛 | 支援内容を知り問い合わせる | 紹介文が重複、問い合わせ導線がない | 企業名と支援内容を対応させ、問い合わせ先を明示 |
| お問い合わせ | 連絡先を確認する | 同じ説明の反復 | XのDMという連絡方法を一度で伝える |
| 404 | 次に進む | 他ページと同じ大きな余白 | 簡潔な説明と復帰リンク |

## デザインシステム
- 基本色：白 #FFFFFF、紺 #182D46、青 #174FBD、淡い青灰 #F2F5FA、補助文字 #586779、罫線 #CCD6E2。
- 日本語：ヒラギノ角ゴシック・游ゴシック・メイリオの順に端末の書体を使用（10月31日更新）。見出しは600、本文は400。英数字の年度・日付はArial、数字幅を統一。本文16px、行間1.9、記事本文は最大42rem。英語の飾り見出しは付けない。
- 全体最大幅1280px。PC左右40px、スマートフォン20px。見出しは左揃え、本文は両端揃えにしない。
- 写真：機体一覧は3:2、活動写真は4:3。機体詳細は元の縦横比を保持し、元画像が小さい機体写真は拡大しすぎない。撮影時期・出典を表示。
- コンポーネント：一覧では写真と文字を直接配置。背景色の面は活動紹介と問い合わせのまとまりに使用。影やグラデーションは使わない。
- 操作：リンクは下線または形状で識別。主要操作44px以上。フォーカス輪郭、メニューのEscape操作、動きを抑える設定を維持。JavaScriptが読み込めなくても記事とナビは見える。
- レイアウト案：

```
トップ     団体名（大）      短い活動説明
           大会写真（大きく、原寸比率に近い横位置）
           最新の活動報告（コンパクトな一覧）
           機体写真2点＋概要
           地域活動（淡色の面、展示写真と本文）
           大会実績／支援者への導線

機体詳細   戻る・年度 → 名前 → 写真と競技情報 → 特徴・大会結果
記事一覧   大会記事（写真大） → 分類 → 写真あり／なしの記事
```

設計段階での見直し：大きな数字と同じカードを並べる案は、この団体の写真や情報量に合わないため採用しない。2025年の2機は比較しやすい並列配置、2024年は展示写真を含む横配置、写真のない年度は文章を中心にする。トップの見出しは抽象的なキャッチコピーではなく、団体の正式な呼び名を使う。
